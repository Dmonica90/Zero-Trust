# Zero Trust: The Infiltrator

A short cybersecurity decision game built in **Articulate Storyline 360**
(published 2026-03-20). Over three in-game days you investigate four colleagues
and decide who is exfiltrating the customer database.

This repository holds the Storyline HTML5 publish exactly as it was exported.
Open `story.html` (or `index.html`) to play it.

The `.story` project file is not in this repository, so this publish is the only
record of the course here.

## Publishing

The course is live at **https://dmonica90.github.io/Zero-Trust/**.
`.github/workflows/deploy.yml` republishes the files as they are on every push to
`main`. The repository's **Settings → Pages → Source** must be set to
**GitHub Actions**.

## The web version

A bilingual (ES/EN) rebuild of the game in React + TypeScript now lives in the
Playground of the [m-design](https://github.com/Dmonica90/m-design) portfolio.
Its source code is kept on the [`web-app`](https://github.com/Dmonica90/Zero-Trust/tree/web-app)
branch of this repository.
